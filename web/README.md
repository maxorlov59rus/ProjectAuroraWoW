# Веб-панель Aurora (PHP)

Панель отвечает за то, что в MMORPG принято выносить на сайт:
дашборд реалмов, регистрация/вход по тем же аккаунтам, что и в игре,
страница загрузки клиента. Игровой клиент на PHP невозможен — WoW
общается бинарными пакетами по TCP, а панель ходит в базу и проверяет
только доступность TCP-портов.

## Требования

- PHP 8.2+ (`pdo_mysql`, `gmp` для SRP6 в `AccountManager`)
- MySQL 8.0 (та же база `acore_auth`, что у AuthServer)
- Composer не нужен: автозагрузка написана вручную

## Запуск для разработки

```bash
cd web
cp config/config.php config/config.local.php   # и заполните auth_db
php -S 127.0.0.1:8000 -t public
```

Откройте `http://127.0.0.1:8000`.

## Структура

```
web/
├── public/index.php        фронт-контроллер и маршруты
├── src/bootstrap.php       автозагрузка, конфиг, рендер
├── src/Auth/               AccountManager (SRP6), AccountException
├── src/Realm/              RealmStatus (TCP-проверка реалмов)
├── views/                  шаблоны (layout + страницы)
├── config/config.php       конфигурация по умолчанию
└── assets/style.css        оформление
```

## Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | Дашборд: реалмы, статус, пинг |
| GET | `/api/status` | JSON со статусом всех реалмов |
| GET/POST | `/login` | Вход, проверка пароля по SRP6-verifier |
| GET/POST | `/register` | Регистрация в `acore_auth` |
| GET | `/download` | Страница загрузки клиента |
| POST | `/logout` | Выход |

## Как работает авторизация

AzerothCore не хранит пароль: в `account.salt` лежит 32-байтовая соль,
в `account.verifier` — SRP6 verifier `v = g^x mod N`, где
`x = SHA1(salt | SHA1(USER:PASS))`. Панель считает тот же `v` из
введённого пароля и сравнивает через `hash_equals`.

Если в сборке AC включена sha256-форма SRP6, переключите
`srp.version` в конфиге.

## Статус реалма

`RealmStatus` делает TCP-connect с таймаутом 2 с и сразу закрывает
сокет. Это не создаёт фантомных сессий: WorldServer ожидает первым
пакет клиента и без него соединение отбрасывает. Результат кэшируется
на `panel.cache_ttl` секунд, чтобы страница не тормозила на мёртвом реалме.
