# UE-клиент Aurora

Клиент World of Warcraft WotLK на Unreal Engine 5.8, подключающийся к
серверу Aurora (AzerothCore). Поэтапное портирование: сначала транспорт и
авторизация, затем мир.

## Текущий этап: 1 из 5 — каркас

Готово:
- Проект UE 5.8, модуль `AuroraClient` (`Runtime`, `Default`).
- Зависимости: `Sockets`, `Networking`, `EnhancedInput`, `UMG`.
- Точка входа модуля, целевые конфигурации Game/Editor.

Не готово (этап 2+): сетевой слой, авторизация, рендер мира.

## План по этапам

| Этап | Содержание | Результат |
|---|---|---|
| 1 | Каркас проекта и модуля | Проект открывается и собирается |
| 2 | AuthServer: `AUTH_LOGON_CHALLENGE` / `LOGON_PROOF`, SRP6 | Получен session key |
| 3 | WorldServer: SMSG_AUTH_CHALLENGE, шифрование ARC4 + HMAC | Соединение с миром |
| 4 | Char-select: список персонажей, создание, вход в мир | Персонаж в мире |
| 5 | Рендер: тайлы карты, модели, камера, UI | Играбельная сцена |

```bat

    AuroraClientEditor Win64 Development ^
    -project="<путь>\AuroraClient.uproject"
```

Или открыть `AuroraClient.uproject` — редактор предложит сгенерировать
project files.

## Важные ограничения

- **Протокол 3.3.5a — бинарный и обфусцированный**: после авторизации
  трафик шифруется ARC4 с ключом из session key, поверх идёт HMAC-SHA1.
  Это придётся реализовать полностью, «на глаз» не получится.
- **Карты**: формат ADT/M2/WMO у WoW закрытый и не совпадает с форматами
  UE. Для этапа 5 нужно либо конвертировать данные в UE-формат, либо
  использовать собственные ассеты. Это самая дорогая часть порта.
- **Права на ассеты**: модели, текстуры и звуки WoW принадлежат Blizzard.
  Переносить их в UE-проект и распространять нельзя. Для теста нужны
  собственные или свободные ассеты.

## Почему не один большой патч

Портирование MMORPG-клиента — это месяцы работы. Ошибка в 1 байте заголовка
пакета ломает всё соединение, а отладить это в UE сложнее, чем в
изолированном тесте. Поэтому этап 2 начинается с отдельного модуля
`Auth`, который собирается и проверяется без запуска игры.
