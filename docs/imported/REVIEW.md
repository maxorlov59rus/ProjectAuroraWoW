## custom-maps — берём

Раскладка:

```
World/Maps/CustomMaps/CustomMaps.wdt
World/Maps/CustomMaps/CustomMaps_<x>_<y>.adt   (10 тайлов)
DBFilesClient/Map.dbc
patch-Z.MPQ
```

Карты привязаны к map ID 5000. В README указаны точки входа:

- Morza Island — `.go xyz -13950 2877 9 5000`
- Valley of Betrayal — `.go xyz 10461 -9574 22 5000`

Что это даёт нашему UE-клиенту: реальные высоты и текстуры вместо
косинусоиды в `FProceduralTerrainSource`. Для этого ADT надо
конвертировать в формат, который понимает `FExternalAssetSource`.
Конвертер живёт в `tools/adt2json/`.

Ограничение: сами ADT — производная работа от клиента Blizzard. Внутри
проекта они допустимы как локальные данные для собственного сервера, но
в публичный репозиторий их класть нельзя. Конвертер этого и не требует:
он читает файлы у пользователя и пишет JSON с полем `license`, по
которому `FExternalAssetSource` решает, загружать ли чанк.

## wow-mod-delves — берём как эталон

Структура, которую стоит перенять:

| Их подход | Что у нас сейчас |
|---|---|
| Один класс — одна ответственность: `DelveRun`, `DelveReward`, `DelveScaling`, `DelveJournal` | Монолиты на 500–600 строк: `CampaignOfLightModule.cpp`, `CampaignOfDarknessModule.cpp` |
| Адаптер к ядру отдельно: `DelveServerAdapter` — единственное место, где есть AC-API | AC-вызовы размазаны по модулям |
| Тесты без запуска сервера: `tests/*.cpp` на синтетических данных | Тестов нет ни одного |
| Документы по подсистемам: `docs/REWARD-DELIVERY.md`, `docs/SCALING-AND-STARTUP.md` | Один `docs/AURORA_CUSTOMIZATION.md` на все модули |
| Явный статус: `BUILD-STATUS.md` пишет прямо «не устанавливать как модуль» | Статус модулей нигде не зафиксирован |

Что не берём: их игровые данные (мобы, награды, квесты) — это чужой
контент. Берём только организацию кода.

## waloriaold-master — не берём

Внутри:

- `scripts/` — Lua (dungeons, raids, SpellAIO, guildbuilding)
- `website/` — старый сайт
- `waloria.exe` — бинарник без исходников
- `Patch-T.MPQ.rar`, `BuildingSystemTemplateSpellDBC.rar`

Причины отказа:

1. **Нет лицензии.** В README «Feel free to use as you wish» — это не
   правовая норма, а пожелание. Без явного текста лицензии код нельзя
   включать в проект под GPLv3.
2. **Бинарник без исходников.** `waloria.exe` нельзя проверить, и его
   нельзя распространять.
3. **Старые патчи** могут содержать контент Blizzard.

Если скрипты нужны — надо запросить у автора лицензию, а не тащить как есть.
