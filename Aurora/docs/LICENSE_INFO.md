# Лицензионная основа проекта Aurora

## 1. AzerothCore — лицензия GPLv2 / LGPLv3

Текст лицензии находятся в корне AzerothCore:

```
E:/azerothcore-wotlk-master/LICENSE
```

- Использование AzerothCore в проекте проходит по лицензии GPLv2 с возможностью LGPLv3.
- Любые изменения в исходном коде AzerothCore (серверной части) должны быть
  распространяемы в соответствии с GPL/LGPL.

## 2. Aurora — кастомный слой лицензия GPLv3

Проект Aurora распространяется под собственной лицензией (GPLv3),
которая в корне проекта:

```
Aurora/LICENSE
```

Aurora — это свободное ПО; вы имеете право на использование, изменение и
распространение кода проекта в соответствии с условиями GPLv3.

## 3. World of Warcraft Wotlk-клиент — авторские права Blizzard

Клиент World of Warcraft Wotlk является авторским произведением и защищён
законодательством компании Blizzard Entertainment.

### Правила использования

- ✅ **Локальное использование**: клиент может быть установлен и запущен
  только самим пользователем/администратором сервера.
- ❌ **Распространение защищённого контента**: копирование, передача,
  аренда, сборка проекта на основе защищённого WoW-клиента (без разрешения
  разработчика AzerothCore и без лицензии на использование) запрещено.
- 🔒 Мы не копируем, не пакуем и не распространяем защищённый WoW-клиент.
  Мы предлагаем **скелет** проекта и инструкции по интеграции из собственных
  источников.

### Альтернативы

Если вам нужен законный клиент:

- Используйте оригинальный WoW-клиент и свяжите его с вашим AzerothCore-сервером.
- Для моддинга клиента используйте официальные дист-пак, если доступно,
  или [Wago](https://github.com/wago/wago-client), [TrinityCore-совместимые клиенты](#).
- Для массовых изменений UI/скрин нужно модифицировать клиент локально
  и распространять только с соблюдением лицензионных правил.

## 4. Изменения в AzerothCore

Если вы вносите изменения в исходный код AzerothCore (серверная часть):

- изменённый файл должен содержать уведомление об изменении и дате;
- проект должен распространяться под GPLv2/LGPLv3;
- вы можете разместить изменённые файлы в `Aurora/` и документировать их.

## 5. Рекомендации

- См. структуру `Aurora/` — в нём кастомный слой не связан напрямую с
  исходным кодом AzerothCore, поэтому его можно переиспользовать.
- Для коммерческого развёртывания уточните лицензию у AzerothCore и
  получайте разрешение на использование клиента WoW от разработчиков.
